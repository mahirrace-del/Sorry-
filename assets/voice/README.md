# Voice recordings

Choose either VOICEOVER-SCRIPT.md (English) or VOICEOVER-SCRIPT-BN.md (Bangla), then save each rendered track in this folder using the matching filename. The filenames are the same in both scripts. Use your own voice or an AI model trained only on your own voice. Do not imitate Nidhi or anyone else.

The script is first-person and written for natural spoken delivery. Keep the pauses and warm tone, but do not add pleading, sobbing, or pressure. The hold-return.mp3 track should make it easy to pause or leave without explanation.

Voice slots are optional. The experience should still make sense with sound disabled.
