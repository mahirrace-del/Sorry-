# Voice recordings

Use the English-only script in VOICEOVER-SCRIPT.md. Save each rendered voice track in this folder using the exact matching filename from that script. Use your own voice or an AI model trained only on your own voice. Do not imitate Nidhi or anyone else.

The script is written for natural spoken delivery. Keep the pauses and warm tone, but do not add pleading, sobbing, or pressure. The opening and hold-return tracks should make it easy to pause or leave without explanation.

Voice slots are optional. The experience should still make sense with sound disabled.
